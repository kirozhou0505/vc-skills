# 从企业材料生成行业研究

把 BP、会议纪要或访谈材料当作确定研究问题的起点，不把企业自述直接当作行业事实。报告研究的是企业所处行业，最后再判断该企业位于何处、还需要验证什么。用户另有范围或格式要求时，以当次要求为准。

## 研究与判断

1. 先从材料提取企业的产品、客户、使用场景、交付物、替代方案和所处价值链。选择最能解释其收入与竞争的细分赛道作为报告主线。若企业跨多个赛道，写清主赛道与相邻赛道的边界，不把所有相关技术都算进同一市场。
2. 用公开资料补齐行业机制、采购逻辑和竞争格局。优先核对公司官网与产品说明、监管或标准原文、论文、年报及其他一手资料；时间敏感的产品、融资、客户和政策信息按本次写作日期核查。区分材料披露、外部已验证事实、分析推断和待核实事项。找不到可靠证据时明确写待核实，不补造市场规模、业绩、客户或技术指标。
3. 先形成行业总判断，再写技术或业务流程为何创造价值、价值由谁获得、客户为何付费、哪些约束可能使判断失效。使用可比较的任务和指标评价竞争者，避免把融资额、产品发布或演示效果当作商业化证明。
4. 按 [报告结构与排版](references/report-pattern.md) 成稿。章节顺序沿用参考报告，具体小节和术语随行业调整；非技术行业可把技术路线改为核心运行机制。章节编号连续，交叉引用与正文一致。研究材料不足时压缩小节，不用套话填满九章。

## 竞品和目标公司

- 竞争格局先用简短分类表说明参与者及竞争方向。重点公司再分别写 **产品、公司特点、竞争位置**，因此总表不重复逐家公司介绍。
- 产品项要解释主要产品解决什么问题、在客户流程中做什么、产出什么。没有已明确产品形态的公司，说明公开信息边界；不推断出一款尚未披露的产品。公司条目不设商业证据项。
- 目标公司用简短概况、竞争位置和重点观察收束行业分析。重点观察应落到可验证的客户任务、部署、效果、复用、成本或授权。默认不写融资状态和估值；用户明确需要时再加入。

## 交付

默认生成可复制到飞书的本地 Markdown 文件。使用标准标题、适度加粗、无序列表和简单管道表格；不使用 HTML、复杂嵌套列表、超链接或双引号。全文不留空行，这是当前参考报告的排版要求；如果用户另有格式要求，依用户要求调整。必要来源用机构或文件名称及日期作纯文本标注，不把网址写入正文。

交付前检查：行业范围清楚，九个一级章节及小节编号连续，表格只承担概览功能，重点公司产品写明用途，目标公司没有未经要求的融资段落，事实与推断可区分，全文没有空行和超链接。保存 `.md` 文件并提供可打开的文件链接。
