# 逐家讲明白企业

默认一次只讲用户点名的一家公司。若用户在行业报告后逐家追问，沿用报告背景，但每家都重新核实关键事实。成稿的顺序和 Markdown 样式参照 [已确认的华大九天示例](references/approved-example.md)；借鉴它的表达方式，不复制其中的公司事实。

## 查证重点

核实公司名称、成立时间、主营业务、上市状态、代表产品、重要发展节点及国内外竞争位置。优先用公司官网、产品资料、交易所公告和年报等一手来源；当前状态按回答时的日期核实。公司自称的领先地位、客户效果或市场份额须注明口径，不能把某个细分领域的全流程推成整个行业的全流程。

找出最能代表公司的核心产品或产品体系。只解释读懂公司所必需的几款产品；若核心产品是一套工具，把关键工具逐个讲清楚，不罗列无关业务线。核实与公司争夺同一客户任务的具名对手，分别判断国内和国际位置。

## 成稿顺序与写法

1. `# 公司名`，随后 `## 公司概况`：自然段说明公司做什么、谁用它、成立多久、是否上市，让读者先知道公司身份。
2. `## 核心产品`：先用一句话说明产品体系，再用简短无序列表逐个介绍，格式为 `- **产品名**：通俗说明它是什么、解决什么问题、用户用它得到什么。` 先说实际用途，再解释必要术语；不把产品说明写成技术手册。
3. `## 用一个例子理解产品`：用一个完整、易懂的客户任务，按先后顺序把刚讲过的产品串起来，交代参与者、遇到的问题、每款产品的作用和最后结果。若无公开客户案例，用假设情境开头即可，不虚构真实客户采用事实，也不追加生硬的证据边界说明。
4. `## 发展历程`：用自然段讲成立背景、核心产品怎样形成、几次重要扩展、上市及目前发展阶段。说明每个节点如何改变公司的能力或市场位置，不堆砌年份。默认不单设营收、利润、融资等财务段落；用户主动问经营表现时再查证并补充。
5. `## 竞争位置`：先讲国内的相对位置和同任务竞争者，再讲国际格局。具体说明公司强在哪里、仍有什么差距、客户为什么可能选它或对手。避免空泛排名和没有依据的绝对化判断。

使用自然、连续的中文段落，篇幅随公司复杂度调整。标题单独成行，标题、正文、列表之间留空行，以便飞书和常见 Markdown 渲染器识别。加粗只包住需要强调的词，不把句号放进加粗标记后又紧接正文；例如用 `**产品名**：`。不用表格、嵌套列表或中文及英文双引号。来源说明应简短，不打断讲解；若用户要求无超链接，用纯文本来源名称。
