# vc-skills

Pedersen Johan / kirozhou0505 的 VC 研究写作技能 monorepo。

A monorepo of VC research writing skills by Pedersen Johan / kirozhou0505.

## Skills

- **investment-report-writing/** — 撰写、改写和润色中文 VC/PE 行业研究、立项与投决材料，强化投资判断并去掉空泛文风。Write and polish Chinese VC/PE industry and investment memos.
- **company-deep-dive-explainer/** — 按公司概况、核心产品、完整例子、发展历程、竞争位置，通俗讲清一家公司。Explain one named company in that order.
- **company-to-industry-report/** — 从企业 BP、会议纪要或访谈出发，写成以该公司为观察对象的中文行业研究报告。Turn company materials into a Chinese industry report.
- **reading-explainer/** — 在当前对话中持续研读材料：补背景，讲主旨和因果，并逐个解释新术语。Keep explaining a text in the current chat, including new terms.

每个技能目录都有 `SKILL.md` 和 `agents/`。前三个另有 `references/`。

Each skill directory contains `SKILL.md` and `agents/`. The first three also include `references/`.
